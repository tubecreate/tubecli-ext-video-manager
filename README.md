# Video Manager Extension for TubeCLI

A comprehensive video management extension for TubeCLI. Supports managing channels, updating metadata, uploading videos to YouTube, and checking upload progress in real-time.

## Features
- **YouTube API Integration:** Seamless Google OAuth token resolution.
- **Channel & Video Browser:** Browse uploaded content with thumbnail generation.
- **Background Upload Queue:** Non-blocking background uploads with SSE (Server-Sent Events) progress streaming to the Dashbaord UI.
- **Web UI:** Directly integrated into the TubeCLI dashboard.

## Installation
Drop this folder into `data/extensions_external/video_manager` or use the TubeCLI Extension Marketplace.
